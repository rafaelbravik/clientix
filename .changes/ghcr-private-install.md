titulo: Instalação autenticada de imagens privadas do GHCR
---
O kit HostGator agora verifica o acesso antes de configurar ou atualizar a instalação e usa o login Docker autorizado para atualizações futuras. O instalador comercial também pode usar um login Docker persistente feito antes de instalar ou atualizar. O PAT fica fora do `.env`; a licença `ACT_...` continua sendo um controle separado.
