titulo: Envio autorizado em nome de atendente pausa a resposta automática
---

Um envio por API só recebe a semântica de resposta humana quando o token tem o escopo específico e o usuário representado é membro ativo autorizado da organização. O token continua registrado como ator técnico e a pessoa representada fica identificada separadamente.
